Project summary

What this project is

  • Interactive Streamlit explorer for short-text embeddings with linked selections across PCA, t-SNE, and UMAP.
  • Pipeline: clean text → TF-IDF → dimensionality reduction → neighbors/clustering → metrics + plots.
  • Goal: quickly inspect cluster coherence, neighborhood structure, and drift across preprocessing variants.
  • Status: stable explorer with selection/undo, search/filter, comparison panel, and export of selections.

Process

What I did

  • Fixed missing points in plots (removed stray shell text in Python) and repaired doc_id ↔ coordinate alignment to eliminate mismatched highlights.
  • Rebuilt PCA layer to use refreshed numpy exports; added artifact loader for bundle switching without manual path edits.
  • Hooked comparison panel to stored neighbor lists; added selection history/undo; made lasso the default drag mode.
  • Added export of selections, cluster stats, similarity heatmap (guarded for size), and filter/search recentering.
  • Wrote regression, reproducibility, and stability tests; added distance metric validation and artifact sanity checks.
  • Generated new visualizations (PCA/UMAP/t-SNE + heatmaps) and documented validation checklist.
What I learned

Key takeaways

  • Index alignment is the linchpin: doc_id → coord mappings must stay consistent across all .npy exports or interactions break.
  • UMAP/t-SNE require careful seeding and config when comparing runs; PCA provides a stable fallback for alignment checks.
  • Interaction reliability (selection, undo, hover) matters more than adding new widgets—stability first, then features.
  • Regression baselines and quick stability runs catch silent drift early; small checklists prevent bad artifact bundles from shipping.
Self-evaluation

Reflection

  • Proud of the stabilized explorer and test coverage; the tool is now usable for real analysis and demos.
  • Would start earlier on alignment validation and automated artifact checks to avoid late-cycle debugging.
  • Next time: add lightweight state persistence (selection/search) across reloads and automate bundle selection via CLI.
