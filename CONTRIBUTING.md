Contributing to Short-Text Embedding Explorer

Thank you for your interest in contributing! This project follows standard open-source research practices.

How to Contribute
1. Fork the repository
2. Create a feature branch
3. Implement changes
4. Add tests in tests/
5. Run tests: pytest tests/
6. Submit a Pull Request

Code Style
- Use standard Python conventions (PEP 8)
- Include docstrings for new functions
- Format code before submitting

Reporting Issues
- Use the GitHub Issues tracker
- Describe the bug clearly with reproduction steps
- Environment details (OS, Python version) are helpful
